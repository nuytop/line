# LINE Message Storage Bot — Project Showcase

Static portfolio page for a LINE Bot project.

## Files
- `index.html` — project showcase
- `style.css` — responsive design
- `assets/` — project evidence screenshots

## Publish
Upload the whole folder to GitHub and enable GitHub Pages, or deploy it to another static hosting service.

## Security before public release
- Never publish the real LINE Access Token.
- Never publish sensitive Google Drive/Sheets IDs unless intended.
- Check screenshots for other people's private information before publishing.
